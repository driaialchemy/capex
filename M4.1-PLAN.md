# M4.1 Visual theme

Status: **built**. Page background is `bg_page.webp`. Sidebar is `bg_sidebar.webp`. Hero is `hero_pipeline.webp`, shown as cropped. Originals are in `assets/source/`.

## Goal

A dark projector theme for the existing Streamlit page. The three background images stay behind the content. Figures, checks, the logbook, and sign-off stay as they are.

## Prerequisite

`capex/assets/` does not yet contain `bg_page.webp`, `bg_sidebar.webp`, or `hero_pipeline.webp`. The folder currently has other images (`anothernew.png`, `brainstorm.webp`, `blogimage1.webp`). Drop the three named files in `capex/assets/` before the build. The "assets present" test needs those exact names.

## Choices

- `apply_theme(assets_dir=None)` returns the CSS string and injects it with one `st.markdown`. The default folder is `capex/assets`. Tests pass a temp folder for the missing-file case.
- A missing image omits only that rule. The function does not raise. The hero in `app.py` is shown only when `hero_pipeline.webp` exists, so a missing file does not crash the page.
- The one-line style now in `app.py` moves into `ui_theme.py`. The four labels keep their words and gain chip classes: AI judgment, Code check, Record, Human.
- Dataframes and the memo get a solid background in the same CSS file. No image sits behind them.
- `st.metric` is styled for the theme. The page does not gain new metric widgets.
